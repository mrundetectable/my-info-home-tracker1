MY INFO HOME TRACKER — INSTALLABLE PWA

Includes:
- index.html: the app
- manifest.webmanifest: install metadata
- sw.js: offline app-shell cache
- icon-192.png and icon-512.png: My Info Home app icons
- logo.png: logo shown in the app header

Publish with GitHub Pages:
1. Create a GitHub repository.
2. Upload every file in this folder to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose the main branch and /(root), then Save.
6. Open the published HTTPS URL in Android Chrome.
7. Use Chrome menu > Install app (or Add to Home screen).

Data is stored in this browser's localStorage. Export a JSON backup regularly.
Import replaces the current list with the contents of the selected backup.
